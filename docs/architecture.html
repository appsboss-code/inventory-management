Factory Inventory Management System

A three-tier demo: Vue 3 single-page app, FastAPI REST service, and in-memory data loaded from JSON files. No database.

Data flow

  1. User changes a filter. FilterBar writes to shared singleton refs in useFilters (period, warehouse, category, order status).
  2. View reacts. A watcher in the active view calls getCurrentFilters() and passes the result to api.js.
  3. Client builds the query. Filters set to all are omitted; the rest become query params on GET http://localhost:8001/api/....
  4. FastAPI filters in memory. The handler runs apply_filters (and filter_by_month for orders) over the lists loaded by mock_data.py.
  5. Pydantic validates the response and FastAPI returns JSON. The dashboard summary also aggregates totals: inventory value, low-stock count, pending orders, backlog count.
  6. Vue renders. Raw results are stored in refs; derived figures and chart geometry come from computed properties.

Inventory has no time dimension, so the month filter does not apply to it. The service is read-only: there are no write endpoints, and restarting the server resets state.
